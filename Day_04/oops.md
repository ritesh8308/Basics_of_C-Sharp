Real World          →       Code
─────────────────────────────────
Bank Account        →       class BankAccount
  has balance       →         double balance
  can deposit       →         void Deposit()
  can withdraw      →         void Withdraw()

Student             →       class Student
  has name          →         string name
  has grades        →         int[] grades
  can get average   →         double GetAverage()




The Four Pillars of OOP's:

Encapsulation  → hide data, expose only what's needed
Inheritance    → child class gets parent's features
Polymorphism   → same method, different behavior
Abstraction    → hide complexity, show only interface
